## Scope and visitor mode

Homepage and documentation shell in Read mode, with one interactive strategy-composition plate.

## Audience, job, action, proof, constraints

- Audience: quant researchers composing event-driven strategies, then Rust contributors and operators.
- Job: understand how an event moves through ordering, bucketing, online statistics, signal logic, and a restart boundary.
- Primary action: open the composition guide and reproduce the pipeline in Rust.
- Proof: executable crate APIs, deterministic replay tests, benchmark evidence, and explicit synthetic-data labeling.
- Constraints: no alpha claims, broker claims, or live-production claims; domain-free substrate stays distinct from the event-shock proving ground.

## Chosen direction and memorable moment

Annotated Event Atlas, composition-first refinement. Approved comp: `.impeccable/mocks/atlas-composition-first.webp`. One event pulse crosses a six-stage typed rail, then resolves into an aligned-time response plot and an inspectable checkpoint ledger.

Do not literalize the comp's invented data scale, asset universe, or evidence-strength label. Keep all demonstration values visibly synthetic and link product claims to implemented code or tests.

## Component and type grammar

- Near-square corners, one-pixel cool-gray rules, no drop shadows, no elevated cards.
- Flat continuous page ground with ruled plates and small registration crosses.
- Plot and path strokes are two pixels; selected-state underline and event pulse are three pixels.
- Archivo Variable carries interface and prose; Recursive Variable carries labels, metrics, and code.
- Type ramp: 12px labels, 15px data and body, 20px section titles, 32px product thesis, 44px homepage statement on wide screens.
- Motion: one event pulse traverses the path after entry; stage selection updates evidence immediately; reduced-motion users receive a static selected state.

## Responsive commitments

- Desktop preserves the six-stage rail and two-thirds plot plus one-third ledger.
- Mobile turns the rail into a vertical sequence, stacks plot and ledger, and keeps chart labels readable without horizontal page overflow.
- Navigation and every control remain keyboard reachable with visible focus.
